# 🌌 AstroCalc

AstroCalc is a lightweight Python tool for performing common astronomy-related calculations.
It’s built for speed, simplicity, and practical use — no giant libraries required.

## ✨ Features
- Distance calculations (AU, light-years, parsecs)
- Orbital period / velocity helpers
- Coordinate conversions (RA/Dec, Alt/Az)
- Time conversions (Julian date, sidereal time)
- Small-body / planet data lookups
