# 🌌 AstroCalc

AstroCalc is a lightweight Python tool for performing common astronomy-related calculations.
It’s built for speed, simplicity, and practical use — no giant libraries required.

✨ Features
🛰 Orbital Mechanics
Orbit Visualizer
Elliptical, circular, and hyperbolic orbits
Multiple input modes (altitude-based, velocity-based)
Scaled central bodies and reference orbits
Hohmann Transfer Calculator
ΔV breakdown (departure, arrival, total)
Visualised transfer, start, and target orbits
Rocket ΔV Calculator
Classical Tsiolkovsky rocket equation
🌌 Astronomy & Astrophysics
Photon Energy / Spectrum Calculator
Stellar Magnitude Calculator
Stellar Spectral Classification Tool
Schwarzschild Radius Calculator
Roche Limit Calculator
Parallax Distance Calculator
